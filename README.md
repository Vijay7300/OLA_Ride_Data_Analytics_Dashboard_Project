# OLA_Ride_Data_Analytics_Dashboard_Project


## Overview
This project presents an interactive **OLA Ride Analytics Dashboard** built using **Power BI**, designed to analyze ride booking trends, revenue, cancellations, and customer behavior.
The dashboard provides a comprehensive overview of ride data, enabling better decision-making through visual insights.

## Key Features
*  Interactive dashboard with multiple views:
  * Overall performance
  * Vehicle type analysis
  * Revenue insights
  * Cancellation trends
  * Ratings overview
*  Time-series analysis of ride volume
*  Booking status breakdown (Success, Canceled, etc.)
*  Dynamic filtering by date
*  Clean and intuitive UI for quick insights


##  Dashboard Insights

###  Ride Volume Analysis
* Tracks daily ride bookings over time
* Helps identify peak demand days and trends

###  Revenue Metrics
* Total booking value: **56.53M+**
* Helps evaluate business performance

### Booking Status Breakdown
* Success rate dominates (~62%)
* Other categories:
  * Canceled by driver
  * Canceled by customer
  * Driver not found

### Total Bookings

* Over **103K bookings analyzed**
